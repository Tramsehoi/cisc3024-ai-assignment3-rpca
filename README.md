# Robust PCA for Video Background Subtraction — AI Assignment #3 (CISC3024)

All code in this repository was generated by an AI assistant, as required by the assignment.
The task: find a recent PCA/LDA-related algorithm with an application to computer vision,
implement it, run experiments, and write a report. The selected algorithm is **Robust
Principal Component Analysis (RPCA)** solved with the **inexact Augmented Lagrange
Multiplier (ALM)** method, applied to background subtraction.

## Method

Stack T video frames as rows of a matrix `M` (T × pixels). A static background is
approximately low-rank; moving objects are sparse outliers. RPCA solves

```
min  ||L||_* + lambda * ||S||_1    s.t.    M = L + S
```

by alternating two closed-form proximal operators:

```
S <- shrink(M - L + Y/mu, lambda/mu)      # element-wise soft-thresholding
L <- SVT(M - S + Y/mu, 1/mu)             # singular value thresholding
Y <- Y + mu * (M - L - S),  mu <- min(rho*mu, mu_bar)
```

`L` is the recovered background, `S` the moving foreground.


Everything runs on CPU; the full experiment takes under a minute. Both experiments
write fresh figures and JSON stats into `results/`.
